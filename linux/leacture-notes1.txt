HardLink Vs Soft Link
Linked File 
types of link 
1)- hardlink 2)- symbolic link(soft link)

1)- hardlink
syntax:-  ln  source destination
- A hard link is an exact copy of a file that points directly to the same data (inode).
- If the original file is deleted, the hard link still works.
- inode number is same 

2)- Symbolic Link (soft link)
Syntax:- ln -s source destination
- A soft link is a shortcut that points to the filename/path of another file.
- if the original file is deleted the soft link breaks.
- inode number is diffrent


Why data is not deleted when original file is deleted (in hard link)?
Because:

 - In Linux, data is deleted only when the inode's reference count becomes zero.

 - 
Each hard link increases the reference count of the inode.


  - If you delete one name (file), the inode still has other names pointing to it.

Only when all hard links are deleted, the reference count drops to 0, and then Linux deletes the actual data.

#how to check inode 
ls -i or ls -li or ls -li /path/of/file

Feature			Hard Link			Soft Link

Points to			File's data (inode)		File name/path

Works if original is deleted	✅ Yes			❌ No 
(breaks)
Different inode?	❌ No			✅ Yes

Can link directories?	❌ No			✅ Yes

Across filesystems?		❌ No			✅ Yes

Types of Networks

1. LAN (Local Area Network)
- 
Covers a small area like a home, office, or school.

 - 
High speed and low cost.
 - 

Connects devices like computers, printers, routers.


 - Usually privately owned.


Example: A Wi-Fi network in your house or office.

 2. MAN (Metropolitan Area Network)

- Covers a city or large campus.
- 

Larger than LAN, smaller than WAN.


- Can connect multiple LANs together.


- Often managed by ISPs or large organizations.


Example: College campuses or city-wide internet (like Pune Smart City Wi-Fi).

3. WAN (Wide Area Network)

 - Covers a large geographic area — countries, continents.


- Slower than LAN due to long distances.
- 

Uses public networks (like the Internet) or leased lines.

 -Expensive and complex to manage.
Example: The Internet, or a bank's network across many countries.

Networking protocols 

TCP (Transmission Control Protocol)

Connection-oriented: Establishes a connection before sending data.


Reliable: Ensures data is delivered in order and without errors.

Slower, but safer.


Uses acknowledgments and retransmission if data is lost.



Used for:



Web browsing (HTTP/HTTPS)


File transfers (FTP)


Emails (SMTP, IMAP, POP3)

 

Think: Like sending a registered courier — tracked and confirmed.



UDP (User Datagram Protocol)

Connectionless: Sends data without setting up a connection.

Unreliable: No guarantee of delivery, order, or duplicate checking.


Faster, with less overhead.


Good for real-time applications where speed matters more than accuracy.

 

Used for:


Online gaming


Video streaming

VoIP (voice calls)


DNS (Domain Name System)

 

Think: Like dropping postcards — fast but not tracked.
